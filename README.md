# Anthony Andino — Portfolio Editorial de Analista de Datos

Portfolio interactivo de alta gama para **Anthony Jafed Andino Marinero**, Licenciado en Informática Administrativa y Analista de Datos. Diseñado con una estética **editorial suiza y arquitectónica** (inspirada en *Edison Fang Workshop*), combinando tipografía de gran escala, fondo marfil cálido y un motor de consultas SQL interactivo.

---

## Características Principales

1. **Diseño Editorial Suizo & Arquitectónico**:
   - Fondo cálido marfil/lino (`#f7f6f2`), tipografía display escalonada y micro-etiquetas verticales.
   - Logotipo geométrico arquitectónico y botón circular `INDEX (=)`.

2. **Menú de Colección en Pantalla Completa (Index Takeover)**:
   - Al abrir el índice, la pantalla completa se transforma en la navegación escalonada:
     - `01 / HOME`
     - `02 / WORK` (Porsalud & Cooperativa La Reyna)
     - `03 / PROJECTS` (RH Enterprise & Dashboard Financiero)
     - `04 / SKILLS` (SQL, Python, Excel, Power BI, PostgreSQL, MySQL)
     - `05 / CERTS` (5 Credenciales oficiales)
     - `06 / CONTACT` (LinkedIn, WhatsApp, Email)

3. **Consola SQL con Tipeo Automático**:
   - Barra de comandos minimalista con efecto de máquina de escribir cuando se seleccionan accesos rápidos.
   - Parser SQL en memoria que soporta `SELECT`, `WHERE`, `LIKE`, `DESCRIBE`, `SHOW TABLES`, `HELP` y `CLEAR`.

4. **Inspector Modal en Pantalla Completa**:
   - Permite visualizar cualquier consulta o sección en pantalla completa con doble modalidad:
     - **Vista Editorial**: Tarjetas con casos de impacto y detalles de responsabilidades.
     - **Vista Grid SQL**: Tabla relacional limpia con exportación a JSON.

5. **Caso de Estudio en Vivo**:
   - Sección dedicada a la reconciliación de los 4 descuadres contables en Cooperativa La Reyna y la depuración de Stored Procedures en Porsalud.
